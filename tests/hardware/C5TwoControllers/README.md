# C5・2コントローラー試験

C5単体でD0/D1/D2を未接続にし、このスケッチをXIAO ESP32C5として書き込みます。
モニター115200を開いてリセットし、バージョン行からDONEまでの全ログを保存してください。
通常の12サンプルとは別の実機検証用スケッチです。

TWAI0は最初の割り当てで診断。終了後、別GPIO D2で最初のスロットを確保し、
開始・送信はせず、その間にCANBridgeで次のスロットTWAI1を診断します。
公式SDKの空きスロット昇順割り当てに依存するため、他のTWAIコードと併用しません。
両方が4項目Passed、Ok、frames=4、RESERVE/RELEASEが0なら成功です。
外部通信や2バス同時通信の試験ではありません。
